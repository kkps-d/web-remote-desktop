# Agent instructions

These instructions apply throughout this repository. Follow the [design guidelines](./docs/DESIGN_GUIDELINES.md) for all code.

## For humans

- Don't talk with unnecessary prose, keep it concise. This applies to documentation as well.

## Commits

- Commit using conventional commit messages style.

## Verify changes

- Run the formatters, linters, type checks and tests relevant to the change (see the README's Testing section).
- For UI changes, check responsive behavior, accessibility, and applicable interaction states.

## Live tests

- You may do live tests if needed without prompting the user

## Linux agent development

- Do Linux agent development on a Linux VM or computer, working inside its desktop session. See [Linux development](./docs/LINUX_DEV.md).
